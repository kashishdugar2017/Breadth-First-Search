# Breadth-First-Search
A python searcher using dicts to find the smoothie-bowl seller

## Why A Queue
- My code finds Rumi before Noah because Rumi is a **First-degree** Friend that means she is closer to me while Noah is only Agastya's Freind 

## Why the Searched List
- If there was no **Searched List** it would never end and go like: Check Rumi, Check Neelu, Check Rumi, Check Neelu ... Forever

## How to run
`python main.py`
- **It prints** : Rumi is a smoothie bowl seller
